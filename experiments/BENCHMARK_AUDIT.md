# External possession benchmark audit

The primary dataset supports an honest held-out **provider-label benchmark**, but
its dead-ball coordinates contain a strong preprocessing shortcut. A high score
here does not establish the same performance on the hackathon's broadcast
tracking. Report both frame macro F1 and possession-spell F1 with the dataset name.

## Data and attribution

Manuel Bassek, Robert Rein, Hendrik Weber, and Daniel Memmert (2025),
*An integrated dataset of spatiotemporal and event data in elite soccer*.

- [Dataset version 1](https://doi.org/10.6084/m9.figshare.28196177.v1), published
  2025-02-02; [article API](https://api.figshare.com/v2/articles/28196177).
- [Scientific Data paper](https://doi.org/10.1038/s41597-025-04505-y), with
  [open full text](https://pmc.ncbi.nlm.nih.gov/articles/PMC11787359/).
- Dataset license: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- Seven Bundesliga and 2. Bundesliga matches are available. Five are used here;
  none is the Barcelona–Athletic hackathon match. No hackathon public ground truth
  or annotations of that match were used for this dataset or model selection.
- Input files are official match information and observed positions XML. We do
  not use events, synced-event timestamps, possession phases, or video.
- `data/external_audit/sportec/article.json` preserves the Figshare manifest.
  Each processed `<match>.json` records its source file IDs and published MD5s;
  downloads and conversions verify both byte count and MD5 before use.

The paper defines `BallPossession=1` as home, `2` as away, and `BallStatus=0`
as inactive, `1` as active. It defines possession through the player controlling
the ball and inactivity through referee interruption. These are explicit provider
labels, not labels generated by our nearest-player algorithm. The paper does not
fully establish how the frame possession labels were produced or validate them
against an independent possession annotation set.

## Fixed split and conversion

The following split was fixed before training or validation scores were observed.
Whole matches, rather than random frames, are the unit of separation.

| Role | Match | Teams | Frames |
| --- | --- | --- | ---: |
| Train | J03WMX | Köln–Bayern | 145,967 |
| Train | J03WN1 | Bochum–Leverkusen | 141,561 |
| Train | J03WOH | Düsseldorf–Regensburg | 137,214 |
| Validation | J03WOY | Düsseldorf–Rostock | 142,536 |
| Test | J03WPY | Düsseldorf–Nürnberg | 146,211 |

There is no frame overlap, but Düsseldorf occurs in train, validation, and test.
This tests another match, not an unseen team or tracking provider. The two unused
matches, J03WQQ and J03WR9, remain available for a future predeclared replication.

Run from the repository root:

```sh
python experiments/audit_dataset.py
# If verified raw files are already present:
python experiments/audit_dataset.py --skip-download
```

The converter writes `data/external_audit/sportec/split.json` and
`data/external_audit/sportec/processed/<match>.npz`. It refuses to overwrite a
different existing split. The NPZ fields are:

- `ball[N,2]`, `players[N,P,2]`: metre coordinates, shifted from pitch-centred to
  `[0,length] × [0,width]`. Outside-pitch coordinates remain outside.
- `teams[P]`: 0 home, 1 away, mapped from explicit metadata team IDs. Roster
  members absent from a frame have NaN coordinates; bench players are not at zero.
- `period[N]`, `timestamps[N]`, `fps=25`, `pitch=[105,68]`,
  `ball_observed[N]`: time and geometry metadata. Timestamp gaps retain halftime;
  no artificial halftime rows are inserted into model data.
- `labels[N]`: `D` if `BallStatus=0`; otherwise `H`/`A` only when status is live
  and possession is explicitly 1/2; all other cases would be `X`.

The converter joins ball and player rows by original frame ID, checks consecutive
IDs within each half and approximately 0.04-second timestamp increments, and
copies coordinates directly. It does not interpolate or forward-fill. All five
converted matches have finite ball XY throughout and no unknown target labels.

`BallStatus`, `BallPossession`, source speed, source distance, source acceleration,
and ball height are not model inputs. In particular, no source target is supplied
as a feature. Height was omitted to match the challenge's available geometry.
Predictors should receive a dictionary without `labels` at inference time.

## Important source artifact: frozen dead-ball coordinates

Every adjacent pair of ball coordinates within a dead-ball run is identical in
all three training matches and the validation match. This is present in the raw
XML; it is not produced by the converter. For comparison, only 0.28–1.17% of
within-H/A adjacent pairs are identical across those four matches.

For a concrete raw example in J03WMX, first half:

| Source frame | BallStatus | Raw X | Raw Y | Raw Z | Supplied speed |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 10130 | 1 | 39.85 | 35.90 | 1.63 | 31.10 |
| 10131 | 1 | 40.07 | 36.14 | 1.60 | 29.25 |
| 10132 | 0 | 40.07 | 36.14 | 0.00 | 29.23 |
| 10133 | 0 | 40.07 | 36.14 | 0.00 | 29.23 |
| 10134 | 0 | 40.07 | 36.14 | 0.00 | 29.23 |

For J03WMX, all 60,495 within-D adjacent pairs have exactly zero displacement.
The raw supplied speed even remains positive while coordinates freeze, reinforcing
why velocities must be derived from geometry and why source speed is excluded.
The audit measurements are saved in
`data/external_audit/sportec/coordinate_audit.json` and cover train/validation only.

The paper describes outlier filtering, smoothing, and operator quality control,
but does not document this freezing mechanism. Its cause cannot be established
from the files alone. Nevertheless, frozen XY acts as a near-direct proxy for the
dead-ball label. Removing explicit target columns does not remove this shortcut.
The benchmark remains useful for H/A possession and sequence modelling, but its
alive/dead performance is likely optimistic for other tracking feeds.

## Evaluation protocol and limits

1. Fit on the three training matches and select parameters on J03WOY only. Freeze
   the model, configuration, and selection rule before scoring J03WPY. Do not
   choose an approach from test scores or retune against the test match.
2. Use the unchanged competition metric through `experiments.metrics`.
   `macro_f1` averages frame F1 over H/A/D. `spell_f1_mean` averages the official
   possession-spell scores across IoU thresholds; these are different metrics.
   Do not describe either simply as "accuracy". Also report actual accuracy,
   per-class F1/support, possession-share error, and observation/target coverage.
3. Preserve unknown reference rows as X. Exclude them using the official scorer,
   rather than dropping rows and joining distant possessions. Insert an ungraded
   separator at half changes and timestamp discontinuities. Model sequence state
   and rolling windows should reset at those boundaries too.
4. The official scorer penalizes prediction X at frame level but fills prediction
   abstentions within valid reference runs for temporal metrics. Report coverage
   alongside spell F1 so abstention cannot hide poor frame predictions.
5. SkillCorner is an auxiliary H/A silver-label benchmark. Its null possession
   cannot be inferred to mean D. With no D reference support the official
   three-class macro F1 is at most 2/3; a present-class H/A macro average must be
   named separately and cannot satisfy the H/A/D target.
6. The primary source uses multi-camera TRACAB tracking, has complete ball XY,
   and supplies the frozen-D shortcut. The hackathon broadcast feed has frequent
   missing ball observations. Artificial observation-gap stress tests may reveal
   sensitivity, but cannot validate real camera occlusion, dead-ball motion, or
   challenge accuracy. Do not interpret them as a substitute for independent
   labelled broadcast data.
7. One held-out match cannot establish broad generalization. A frame or spell
   bootstrap on that match is conditional uncertainty, not uncertainty across
   matches, leagues, or tracking providers. The test also reuses one team from
   training. Any claim of reaching 0.9 must identify the exact metric, test match,
   provider labels, frozen-coordinate caveat, and lack of challenge validation.

Metrica sample data was considered but not selected for the primary benchmark:
the available event stream does not itself establish an explicit, independently
validated framewise H/A/D possession target. Deriving targets from the same
nearest-player heuristic being tested would be circular.
