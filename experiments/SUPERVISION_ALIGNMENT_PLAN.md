# Supervision alignment: provider definitions, source heads and full-match coverage

Status: proposed experiment; feasibility reports and synthetic prototypes prepared.
Date: 31 October 2026. Planning base: `f9a741a`.
No real-data calibration, model fitting or candidate evaluation is reported here.

## Question and sequence

Does aligning SoccerNet silver supervision with the target possession definition
improve full H/A/D recovery over the adopted dense D2 recipe? Test label semantics
first, separate output heads second, and complete stoppage coverage when suitable
data become available. Each stage has its own freeze; this plan is not a frozen
execution declaration. No fresh manually labeled match is a prerequisite.

The baseline is `joint_gru_sn_dense_ensemble_v1`. Manifest SHA-256:
`76f18b3fa218e4dde357454dc3206b7eeb28ab97eda2862007fff8c987c04ec5`;
policy SHA-256:
`f63c4bd69881acaa8abadccf515308ebd66890106a24e5f550373a4d20859165`.
The [dense study](SOCCERNET_DENSE.md) documents the touch rule; the
[saved study report](results/sn_dense_v1_progress.md) motivates these mechanisms.
Do not interpret agreement with GAR-valid labels generated by the same rule as
neutral possession evidence.

## A — Diagnose and calibrate the labeling rule

Hypothesis: systematic event-to-possession definition differences can be reduced
by a small training-only calibration that transfers between matches/providers.
Falsification: disagreement persists on held-out training matches/providers, or
improved label agreement fails to improve downstream development spell F1.

First audit raw event schemas, team identities, event timestamps, controlled vs
uncontrolled touch information, OUT/restart coverage and label provenance.
Sportec has provider-reference labels; Metrica's existing dense targets are
event-derived silver. Agreement with Metrica can therefore measure agreement
between rules using the same underlying annotations, not independent truth.
Do not synthesize missing touch semantics from reference possession labels.

The [calibration workstream](PROVIDER_TOUCH_CALIBRATION.md) owns schema findings
and a bounded candidate grid. Select rule parameters only inside canonical TRAIN
matches with whole-match cross-validation. For a full-provider fold exclude that
provider from calibration as well as model/normalizer training. No access to the
five selection targets for rule fitting. If no eligible provider has the required
events, mark the calibrated arm blocked and retain the original rule.

Before rebuilding GAR TRAIN labels, seal the mapping, finite grid, training-only
selection rule and parameter values per outer fold. Preserve unknowns, native
masks and match/half/time breaks. Measure coverage separately so abstention cannot
manufacture improved agreement. Report H/A confusion, D precision/recall, all five
official spell IoUs, eligible boundary error and complete/censored spell counts.

## B — Isolate source-specific output projections

Hypothesis: a shared recurrent representation with separate target-task and GAR
output projections reduces conflicting supervision while preserving useful
transfer. The target-task projection is always used for development/deployment,
including an unseen provider. No organizer-specific flag or learned head exists.

The [head workstream](SOURCE_CONDITIONED_HEADS.md) owns the prototype. Keep shared
H/A and player-only D recurrent paths; do not introduce ball inputs to D. Clone
the same starting projection into each source head. GAR loss updates its own
projection plus shared features; original-provider loss updates the target
projection plus shared features. This isolates output semantics, not all domain
effects. Extra projection parameters are an explicit capacity difference.

Initial proposed matrix, with original v1 GAR labels throughout:

| Arm | Label rule | Output projections | Purpose |
| --- | --- | --- | --- |
| C | v1 | Shared H/A and D | Matched dense D2 control |
| H | v1 | Separate target/GAR H/A; shared D | Isolate team semantics |
| HD | v1 | Separate target/GAR H/A and D | Increment over H isolates D separation |
| L | Calibrated per fold | Shared H/A and D | Isolate label-rule effect; conditional on A feasibility |

No combined calibrated-plus-head arm in this initial matrix. A combination needs
a later declaration; do not add arms after looking at development scores.

## C — Conditional full-match coverage study

The [coverage workstream](FULL_MATCH_STOPPAGES.md) owns the readiness audit.
Action spotting events alone do not establish continuous tracking or dense
live/dead labels. Require aligned tracking, match/half clocks, measured observation
masks and sufficient annotation to identify stoppage starts and restarts.

After availability is verified, freeze a separate coverage study: equal-budget,
same-label-rule clip-style versus continuous/stoppage-complete sampling from the
same eligible TRAIN games. Match unique supervised rows/hours where possible and
report duplication and live/dead mixture; separate the coverage effect from an
hours-only control. Keep network context at five seconds initially. A longer
context arm needs a separate hypothesis given the previous negative context study.
Score complete and censored stoppages separately; do not bridge tracking breaks
or fill unknown reference intervals to create apparent full-match labels.
